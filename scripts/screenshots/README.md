# README screenshots

`index.html` renders the real uttr UI in a browser with a sample backend (`mock.ts`), so the
screenshots in `docs/images/` can be retaken after UI changes without personal data in them.

1. `npm run dev`
2. Open `http://localhost:1420/scripts/screenshots/index.html#/ai` (any route: `/history`,
   `/snippets`, `/style`, `/models`, `/settings`). Add `?theme=dark` before the `#` for the dark theme.
3. Set the window to 900 x 620 (the app's default size) and take the screenshot.
