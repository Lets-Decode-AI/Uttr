## Design Context

### Users
People who write a lot at a desktop computer — developers, writers, support and ops staff — and want to
talk instead of type. They open the uttr window rarely and briefly: to check stats, pick a model, tweak
a setting or find an old dictation. The real work happens in other apps; the window must be calm,
scannable and never in the way. Privacy-minded: speech runs on their own machine.

### Brand Personality
Calm, exact, quietly confident. A well-made tool, not a toy and not a "platform". The interface should
make people feel in control and that their data is safe. No hype, no glow, no gradients-for-the-sake-of-it.

### Aesthetic Direction
- Soft, premium desktop dashboard in the spirit of the reference shots (Panze studio dashboard, Cryptfy
  wallet, Fitness/HR dashboards): one large rounded "sheet" of content on a slightly darker canvas,
  generous radii (16–24px), roomy cards with hairline borders instead of heavy shadows, pill-shaped
  controls, a filled dark-ink pill for the selected state, large light-weight headings.
- Brand: forest green (#274B40) stays the accent and logo colour. Neutrals are cool-soft, faintly tinted
  toward forest (OKLCH hue ~165). Forest-ink (very dark green) is the "black" for pills and primary buttons.
- Navigation: labelled pill sidebar (not an icon rail).
- Theme: light first, with a matching dark theme (deep green-black canvas, lifted panels, pale-mint accent).
- Type: Urbanist (display, numbers, headings — light/regular at large sizes) + Hanken Grotesk (body/UI).
  Both bundled locally via @fontsource-variable (the app never needs the network for fonts).
- Anti-references: macOS System Settings clone, generic shadcn grey, neon-on-dark, purple gradients,
  side-stripe callouts, gradient text, icon-tile-above-every-heading.

### Design Principles
1. One sheet, few containers. Content sits on a single soft panel; cards only where they group data.
2. Hierarchy through size and weight contrast, not colour. Big light numbers, small quiet labels.
3. Accent is rare. Forest/ink marks the selected item, the primary action and live state — nothing else.
4. Pills for choices, rounded cards for content, hairlines for structure.
5. Motion only for state changes, ease-out, under 250ms; respect reduced motion.
